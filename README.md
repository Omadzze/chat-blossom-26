# Chat Companion

I'm building mobile app. 

The mobile app would be like a chatbot system with the design close to the "Gemini" mobile app. It will be cross-platform meaning it will work in Androind and IOS so i'm building design for it. I will use Flutter to build the project.

So basically we have first screen which is welcome screen first photo that i provided, then when user typed something and clicked sent it then became like photo 1. 

We would have chat history button from top left side i put it there red dot and mentioned in photo. When user clicks button it then will go to the chat history where he could see historie of previous chats like in image 3.

So overall i want to have responsive UI that will be dynamically change on different UI screens since it is very important.
